# SoundTrackPlayer(仮称)

## 概要
ゲームなどでよく使用されている、無限ループ可能な楽曲に特化した楽曲プレイヤーです。

## 特徴

1. 設定したループ区間を繰り返し再生できます。

	- イントロから再生を開始し、ループ区間を指定した回数分再生したのち、アウトロを再生します。
	- ループ区間の終了位置から開始位置へのジャンプの際にギャップが生じないため、自然にループ再生できます。
	- ループ区間やループ回数の設定は楽曲ファイルのサイドカーファイルとして保存します。
	(例: 楽曲ファイルが "track01.flac" の場合、サイドカーファイルが "track01.flac.toml" として保存されます。)

2. プレイリストを読み込んで再生できます。

	- プレイリストに登録された楽曲を連続して再生できます。

3. ループ区間の設定を補助する機能があります。

	- ループ区間の終了位置が指定されていれば、ループ区間の開始位置の検出が可能です。
	- 誤った位置が検出されてしまうことがあるため、あくまで補助としてご使用ください。

## 対応 OS
- Windows 11

## 対応している楽曲ファイルの形式
本アプリケーションが使用しているライブラリ(SoundFlow)の対応形式に準じます。

- mp3
- flac
- wav (PCM)

## 対応しているプレイリストの形式

- *.m3u8 (UTF-8 でエンコードされた m3u ファイル)

## 制限事項

1. 現在のところ楽曲ファイルのメタデータを読み取る機能がありません。楽曲やプレイリストはファイル名で表示されます。

2. プレイリストを編集する機能は未実装です。他の楽曲プレイヤーでプレイリストを作成して読み込んでください。

## 使い方

### 1 曲だけループ再生する
1. SoundTrackPlayer.exe を実行します。
